A LITTLE ABOUT THIS SPACE

你好，欢迎来到
我的数字花园。

欢迎来到 WayneLAB。这里是一个持续生长的个人知识空间，整理计算机、数学与机器人的学习笔记，也记录把知识转化为实践的方法。

温故而知新

学习不只是收集答案。更有意思的部分，是用自己的语言重新解释一个概念，用一个小例子检验理解，再把零散的知识连接起来。这个小站就是这一过程的记录。

你会在这里读到什么

  • 计算机：从数据结构到操作系统，理解程序背后的原理。
  • 数学：连接几何直觉、公式推导与具体问题。
  • 机器人：探索感知、规划与控制的闭环。
  • 学习方法：把读过的内容，变成可以再次使用的理解。

保持联系

欢迎通过 GitHub 交流。如果你喜欢安静地阅读，也可以通过 RSS 订阅更新。内容会随学习持续修订，愿这些笔记也能成为你的思考起点。
