第一次使用？创建一个访问令牌
  1. 打开 GitHub 令牌设置 ↗，选择你的账号作为 Resource owner。
  2. 选择 Only select repositories，仅勾选 wayneliang94.github.io。
  3. Repository permissions 中将 Contents 设为 Read and write；Metadata 保持 Read-only。
  4. 设置合理有效期，创建后在此粘贴令牌。

令牌只保存在当前页面内存，刷新或退出后需重新登录。文章保存在你的 GitHub 仓库中。
